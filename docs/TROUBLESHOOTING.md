# 故障排查

| 现象 | 处理与保护 |
| --- | --- |
| 提示系统不支持 | 需要 Windows 10 22H2（19045）或 Windows 11 x64；不支持 32 位和 ARM64 原生版 |
| 下载慢或失败 | 查看网络检测与脱敏日志，核对 nodejs.org、registry.npmjs.org；必要时配置 Windows 的可信代理后重试，不运行网上未知修复脚本 |
| 企业代理/证书错误 | 由组织管理员正确部署企业证书；不关闭 TLS 验证。安装器没有内置代理凭据输入框 |
| 下载中断 | 完整且 hash 正确的缓存复用；`.partial` 不信任，重试时重新下载。不是 HTTP Range 字节续传 |
| npm 安装中途失败 | 失败代不被设为活动环境；重试创建新一代。保留目录便于诊断，不清空全局 Node |
| DSH 启动超时 | 查看日志中的退出码/启动错误；确认选定版本、端口和插件正常。不会把页面 200 或端口开放当作就绪 |
| 3080 被占用 | 安装器保留原进程，实际打开系统分配的本机端口。不要照抄默认地址 |
| 浏览器显示登录/认证错误 | 使用 BigFish「打开 DSH」重新携带当前进程的启动凭据；不要分享地址中的 token |
| 插件已安装但未加载 | 点击修复安装，使用当前审核组合。没有自动执行 allow-version 绕过兼容检查 |
| GUI 关闭后机器人离线 | 本版设计为关闭即停止。保持 BigFish 打开，或再次进入管理页启动 |
| API Key 无效/余额不足 | 在 DSH 设置 → 模型 与服务商控制台检查；安装器不验证或存储密钥 |
| QQ/微信扫码不可用 | 刷新二维码，查看插件诊断、账号权限和平台服务状态；安装器不能批准平台权限 |
| B站 Python 失败 | 基础安装保留；可重试可选步骤。不要根据旧教程覆盖全局 Python 或添加 Defender 排除项 |
| 安装目录没有写权限 | 高级选项选择自己的可写目录；此操作不会自动移动旧工作区 |
| 状态文件损坏 | 停止自动覆盖。备份 `%LOCALAPPDATA%\BigFish\state.json` 和数据目录，检查 JSON/版本；选择新的私有运行目录可以恢复部署，旧数据继续保留 |
| Windows 提示未签名程序 | 仅从可信 Release 下载并核对 SHA-256。当前交付未使用签名证书，不建议关闭 SmartScreen 或 Defender |

## 诊断文件

管理页 → 查看日志 → 打开日志文件夹。`bigfish-*.log` 进行 API Key、Bearer、Cookie、查询 token、代理口令与用户主目录脱敏。日志可记录软件版本、阶段、HTTP 状态、退出码和错误分类。

自动脱敏不能保证识别所有第三方自由文本秘密。分享前仍检查一次；不要附带 DSH 原始日志、凭据文件、二维码、聊天记录或完整用户目录。BigFish 不自动上传任何日志。

插件安装前的配置清单备份位于私有数据目录 `backups`。备份可能包含用户配置中的秘密，应按凭据保管。恢复旧配置需要先停止服务、备份当前版本，手动比较文件；BigFish 不执行会删除用户数据的自动回滚。

## 空间与卸载

DSH 自身及依赖、缓存可能占用超过 1 GB；这来自上游体积。B站依赖另占空间。本地转写模型默认不下载。安装器不自动删除旧运行环境代和用户备份，避免数据丢失；可人工备份后清理不再使用的旧代。

Inno Setup 卸载只移除程序文件与快捷方式，保留 `%LOCALAPPDATA%\BigFish` 和 `ai-fish` 工作区。要删除数据，请由用户另行明确操作并先备份。
