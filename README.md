## 🚀 三步开始

1. 下载对应的 **EXE，双击运行**，点击「一键安装」。首次安装需要联网；不必预装 Node.js、Python 或 .NET。
2. 安装完成后，在「模型与绑定」页填写自己的 **DeepSeek API Key** 并保存。其他服务商在 DSH 模型设置中配置。
3. 需要 QQ / 微信消息接入时，按软件内的引导完成平台授权；B 站功能可选。
